# Handover — 2026-08-20

Written after the corrected grid executed under both fairness axes and the primary contrast
was computed. Supersedes `HANDOVER_2026-08-19.md`, whose one-line state — "no allocation
claim survives" — was true of the run it described and is no longer true of the project.

## One-line state

**The apparatus works, the grid ran under both budget conditions, and the preregistered
primary contrast is a null.** Joint time-and-mode allocation is practically equivalent to
the strongest implemented non-joint baseline. `CLAIMS.md` C-002 is tested and **not
supported**, on evidence rather than on a failed precondition. Three secondary contrasts
are admissible and locate the effect: targeting under-covered modes matters, timing does
not, and combining them equals targeting alone.

## What happened

25 chains, 5 policies × 5 frozen seeds, horizon 10, on 2× RTX 4090, in four seed-block
phases (`DECISIONS.md` P-012). Every chain completed; none failed; none certifies invalid.

Full record: `docs/runs/primary_pilot_v2_2026-08-20_results.md`.

## The result

| | |
|---|---|
| **Both axes hold** | Human spread across spending arms **0.0381%** against 0.2000% permitted. Total optimizer tokens **identical at 16,678,912** for every chain in every arm — 0.0000% spread. `run_pilot --check-only` exits 0 |
| **Certification** | **25 `valid_with_limitation`, 0 `invalid`**, read from the per-chain report in `validation.json` — not from an aggregate exit code, which is the error F-021 recorded |
| **Primary contrast** | joint − `selection_only` = **+0.01026, 95% CI [−0.00916, +0.02968]**, +0.45% relative, against an equivalence region of ±0.05073. Interval lies **wholly inside** it, reaching 0.0297 |
| **Confirmatory** | Tail retention agrees: +0.00003, CI [−0.00100, +0.00105] |

**This is equivalence, not insufficient power.** The design is sized for three chains per
arm at the preregistered threshold and ran five. It is **not** evidence that joint is
worse — the interval covers zero.

## The secondary contrasts, all admissible

| Contrast | Effect | 95% CI | Reading |
|---|---|---|---|
| `random` − `no_rescue` | −4.04% | [−0.121, −0.092] | spending at all helps, at identical data volume |
| `selection_only` − `random` | −9.59% | [−0.269, −0.218] | which examples you buy matters, and matters more |
| `schedule_only` − `random` | −0.41% | [−0.036, +0.016] | when you spend does not, on the primary outcome |

The `schedule_only` null replicates the earlier grid's one clean contrast, now with both
axes holding rather than one.

**One disagreement, and it must travel with the timing claim.** On the confirmatory
tail-retention outcome, `schedule_only` − `random` is +0.00766, CI [+0.00563, +0.00968] —
an interval *excluding* zero, at 0.87% of the random level. Timing does something small
that one preregistered outcome detects and the other does not. `docs/evidence/claim_evidence_matrix.md`
makes pairing this with any timing statement a mandatory rule, not a stylistic preference.

## What P-011 bought

Displacement was accepted unvalidated — "no chain has run under it". 25 chains have now run
under it and totals are identical across arms to the token. That is what converts "spending
helps by 4%" from a confounded observation into a statement about the *origin* of the data
rather than its quantity: the control trains on exactly the volume every spending arm does.

## Two infrastructure defects, and what they cost

| ID | What | Cost |
|---|---|---|
| F-025 | `--cuda-device` pinned subprocesses but not the launcher, which is where evaluation runs. All four shards evaluated on GPU 0 | ~1 h, no science |
| F-026 | The checkpoint is written at the *end* of a generation, so resume restarts on the generation an interruption was inside — whose `model/` dir the dead attempt had filled, and which upstream refuses to overwrite | ~2.6 h, no science |

Both stopped chains from *starting*; neither corrupted a chain that finished. Roughly 3.6 h
of pod time. **The defects that cost science were the quiet ones** — a guard checking one of
two named axes (F-021), a reconciliation that never bound (F-020), a documented exit code
inverted against its implementation (F-024). Loud failures are cheap.

## Four analysis defects fixed after the run, all the same shape

Each was a statement true of one run, written where nothing could notice it becoming false.

1. `generate_pilot_outputs.py` **hardcoded a refusal** to compute the primary contrast,
   naming F-020. Now measures both axes from the chains and gates on them; run 1 still
   correctly refuses.
2. The figure legend labelled `joint` "(underspent)" from `arm == "joint"`. Now derived
   from realised spend.
3. **Wall time** took a max over shard summaries — right for one concurrent launch, wrong
   for four sequential phases. A single max returns 3.35 h, which is phase 4, not the run.
   Three figures are now emitted: 5.96 h clean, 8.53 h productive, 9.56 h including the
   killed attempts.
4. `reproduce_pilot_table.py` **closed by asserting the run was invalid**. Now read from
   the measured spreads, and its published values are keyed by run so both grids stay
   independently checkable.

## One judgement call that deserves a second opinion

Three conventions existed for the 2% threshold's denominator. Both documents that settled
U-006 compute it against the fresh-random mean (0.05049 = 2% of 2.52454); the generator used
the strongest baseline. The code now uses the documented convention.

**This is a threshold denominator touched after primary outcomes were open**, which is
exactly what U-006 exists to constrain. Two things make it defensible and both are recorded:
the verdict is identical under either convention (±0.05073 and ±0.04586; the interval reaches
0.0297), and both figures are emitted as macros so a reader can check rather than trust.
F-026a carries the full note. If an owner prefers the original convention, the conclusion
does not move.

## Things a fresh session should know

- Result numbers come from `paper/tables/pilot_macros.tex`, generated by
  `scripts/generate_pilot_outputs.py`. Prose cites macros; **a bare decimal in a section is
  a test failure**, deliberately.
- Artifacts are in `results/runs/primary_pilot_v2_2026-08-20/`. 65 files tracked; the 25
  `run_manifest.json` files (162 MB) are not, but `ARTIFACT_HASHES.json` makes an archived
  copy verifiable. **The tarball outside the repository is the only copy** and costs ~$18
  and 6 h to recreate.
- `validation.json` and the generation-0 reference snapshots are now tracked, for both runs.
- **Wall time for a phased grid is the sum of per-launch maxima**, not the max over
  summaries.
- Validator exit codes: `0 valid / 1 limited / 2 invalid / 3 usage` (F-024). `run_pilot
  --check-only` is a *different* tool with only `0` and `1`. Confusing them is how F-024
  happened.
- **Heredocs here eat backslash escapes.** Use Write/Edit for anything containing them. This
  bit twice more in this session.
- `git add -A` has swept in unwanted directories. Stage explicitly.
- The pod bills while idle. Chaining phases with a failure guard removed the handoff gaps
  that cost roughly an hour twice before.
- `tests/scripts/test_run_chain_guard.py::test_a_config_with_no_freeze_status_still_launches`
  fails on this machine — a bash subprocess cannot import the package. It is environmental
  and predates this work. 809 pass.
