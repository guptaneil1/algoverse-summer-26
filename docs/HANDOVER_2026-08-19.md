budget equality fails") applies.

Full record: `docs/runs/primary_pilot_2026-08-18_results.md`.

## What the run delivers

**Between-chain variance**, measured within arms and therefore unaffected by the spend gap.
Conservative paired SD 0.02972 across the budget-matched arms. That sizes a paired
80%-power design at **3 chains per arm** for the preregistered 2% threshold — the frozen
five-seed set already exceeds it.

**This inverts the planning assumption.** Chain count was expected to be the binding
constraint on a powered study and is not. Re-running the frozen grid with F-020 fixed is
already a powered test at 2%, for ~$20 and 6.8 hours. Derivation:
`docs/decisions/powered_design_sizing_2026-08-19.md`.

**Secondary contrasts** over the 20 budget-matched chains: selection beats random by 8.37%
with a wide margin; timing does not differ detectably from random; spending beats not
spending by 4.28%. `PREREGISTRATION.md` forbids these substituting for the failed primary,
and the results document says so beside them.

## Five defects, all found after a passing dry run

`FAILURE_LOG.md` F-016 → F-020a. Every one was invisible to both the dry run and a
then-740-test suite.

| ID | What | Would have cost |
|---|---|---|
| F-016 | Launcher's budget guard could never pass — no config with a control arm could satisfy exact equality | A run that flagged itself, exit code 0 |
| F-017 | Corpus paths resolved against the upstream checkout | All 25 chains dead in seconds |
| F-018 | Two more copies of F-016's rule in the certification path | 25 sound chains, every one certified invalid |
| F-019 / F-019a | Partition provenance declared in a vocabulary the manifest builder did not read; then the fix verified against the config on disk rather than the config the launcher builds | Every chain uncertifiable, unrecoverably |
| F-020 / F-020a | Terminal reconciliation raised `joint`'s cap but not its floor | The primary contrast, and the run |

**Three of these share a shape:** a check whose intent was documented and whose
implementation did not achieve it, with no test asserting the intent. A guard that has
never been observed to bind is a guard whose binding is unverified.

**Two limits on the dry run are now known and written down.** It prints the upstream
command instead of executing it, so nothing depending on the subprocess's working
directory, filesystem or environment is covered. And policies that score candidates
allocate from simulated statistics, so **budget matching for score-dependent policies is
not testable by simulation** — `random` and `schedule_only` reproduced their dry-run spends
to the token; `joint` did not.

The step that caught all five is now required: `docs/RUNBOOK_PILOT_LAUNCH.md` §5a, one real
chain plus `validate_run.py`, before any grid.

## Things a fresh session should know

- Result numbers in the manuscript come from `paper/tables/pilot_macros.tex`, generated by
  `scripts/generate_pilot_outputs.py`. Prose cites macros; a bare decimal in a section is a
  test failure, deliberately.
- Pilot artifacts are in `results/runs/primary_pilot_2026-08-18/`. Chain results are
  tracked; the 162 MB of manifests are not, but `ARTIFACT_HASHES.json` makes an archived
  copy verifiable. The archive is a ~36 MB tarball held outside the repository.
- Heredocs here eat backslash escapes. Use Write/Edit for anything containing them — this
  bit twice more this session, once in a LaTeX regex and once in a `\n` inside a shim.
- `git add -A` has swept in unwanted directories three times. Stage explicitly.
- `results/runs/**` is gitignored except chain results, summaries, the aggregate, the hash
  ledger and READMEs. The rule needs `**`, not `*` — the latter re-includes directory
  contents wholesale.
- The pod bills while idle. The last run finished around 04:25 and was noticed at 05:24.
