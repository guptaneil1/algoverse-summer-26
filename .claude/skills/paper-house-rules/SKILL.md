# House rules for `paper/`

These are constraints, not style preferences. Several are enforced by tests; the rest exist
because breaking them has already cost this project a day of documents saying something
untrue. Read this before editing prose that states a result.

## 1. No bare decimals in section prose — enforced

`tests/analysis/test_generated_outputs.py::test_committed_paper_sections_contain_no_hardcoded_result_numbers`
fails on any `\d+\.\d+` in a non-comment line of `paper/sections/*.tex`.

Every result number comes from `paper/tables/pilot_macros.tex`, generated by
`scripts/generate_pilot_outputs.py` from `chain_result.json` artifacts. Prose cites the
macro. If a number you want does not exist as a macro, **add it to the generator** — never
type it.

Corollary, also enforced by `test_headline_values_trace_to_artifacts.py`: every `\Pilot*`
macro a section cites must be defined. An undefined macro is not a bare decimal, so it
passes the first check and would surface as a missing number in the PDF.

## 2. Banned words

`first`, `optimal`, `prevents collapse`, `solves`, `state of the art`, unqualified `novel`.

Negated use still counts — "we do not claim the policy is optimal" was rewritten rather than
defended. Ordinal enumeration ("First, ... Second, ...") is fine; precedence claims are not.

## 3. Two mandatory pairings

From `docs/evidence/claim_evidence_matrix.md`. Each exists to stop a true sentence carrying a
false implication.

- **Any timing claim** must appear with the confirmatory-outcome disagreement, or be
  explicitly scoped to the primary outcome. Timing is null on NLL-regret AUC and *not* null
  on tail retention. "Timing does not matter" unqualified is false.
- **Any statement of the null** must appear with the three unimplemented comparators.
  Without them it reads as "nothing beats selection-only", which the run cannot support: the
  oracle upper bound that would measure the headroom was never built.

## 4. Which outcome template is in force

`paper/outcome_contingent_language.md` is precommitted and **must not be edited to fit the
result**. Currently in force:

- **Template 2, Null** — the primary contrast. The interval lies inside the equivalence
  region.
- **Template 5, Mixed across metrics** — the timing contrast.
- **Template 8, valid_with_limitation** — all 25 chains.
- **Template 4, Uncertain/underpowered, does NOT apply.** This is the one a reader assumes
  from a null. The design is sized for three chains per arm and ran five; the interval is
  inside the equivalence region, not merely wide. Never soften the null into "underpowered".

Template 9 ("No primary result at all") governed the superseded grid and no longer applies.

## 5. What the result may and may not say

`CLAIMS.md` C-002's "Allowed wording now" block is authoritative and carries the exact
permitted sentence. Load it before writing a claim.

Never write: that joint allocation is *worse* than selection-only (the interval covers
zero); that selection-only is near a ceiling (unmeasured, comparator 7 absent); that timing
never matters (see pairing above).

C-004's novelty claim, wherever it appears, carries all three modifiers: *recursive*, *fixed
lifetime human-token budget*, *matched non-joint baselines*. It remains blocked on external
review and no empirical result licenses it.

## 6. Scope every empirical sentence

One budget, one horizon, one corpus, one model. "At this operating point" is load-bearing,
not decorative. A sentence that generalises past GPT-2 / WikiText-103 / horizon 10 / a
750,000-token budget is wrong regardless of how well it reads.

## Before you commit

```bash
.venv/Scripts/python.exe -m pytest tests/analysis -q
.venv/Scripts/python.exe -m ruff check .
```

If you regenerated tables or the figure, re-record digests or the provenance test fails:

```bash
.venv/Scripts/python.exe scripts/record_paper_provenance.py
```
